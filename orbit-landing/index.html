What it does

Four things, one app

Each is a real, working feature in the current beta — not a mockup.

C

Communities & Clubs

Create, join, post, and chat inside student-run communities or official college clubs — one shared structure for both.

E

Events

A live feed of what's happening on campus, in one place instead of scattered across posters and group chats.

T

Locali-Tea

An anonymous, 48-hour confession feed for honest campus conversation — anonymity enforced server-side, not just in the UI.

M

Interest matching

Communities and posts are surfaced based on the interests you actually tag — not a generic trending list.

A note on the repository

This page is intentionally the public face of Orbit, not the codebase. Orbit is being developed toward a commercial launch, so the full source — database schema, security policies, and complete implementation — is kept in a private repository. This page exists to give judges and reviewers a working link without exposing the product's internals ahead of launch. Happy to walk through the actual code live if that's useful for evaluation.
